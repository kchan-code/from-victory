## 4. Pricing — diagnosis and corrections (2026-09-22)

This honors the approved "at or below web" rule.
- First `prices --apply` failed: `POST /v1/subscriptionPrices → 409 ENTITY_ERROR.RELATIONSHIP.INVALID "An error occurred while processing the pricing information."` The request sent `attributes: { startDate: null }`. Apple's OpenAPI schema (`SubscriptionPriceCreateRequest`, downloaded 2026-09-22) defines `attributes` as optional with `startDate` (string), `preserveCurrentPrice` (boolean), `planType` (enum) — a JSON `null` is not a valid value for any of them. Relationships: `subscription` (required), `subscriptionPricePoint` (required), `territory` (optional). **Fix applied to the script: no `attributes` object at all; relationships exactly as specified.** The subscription also had no availability record (`GET …/subscriptionAvailability` → 404); the script now creates USA availability (`SubscriptionAvailabilityCreateRequest`: `availableInNewTerritories` required boolean + `availableTerritories`) before the price, because availability is required for a sellable product regardless. No other trial-and-error fallbacks remain in the script.
- **Small Business Program (P4): UNCONFIRMED.** The $5.00 point reports `proceeds` 4.25 and `proceedsYear2` 4.25 (85% both years). Under standard terms first-year proceeds would be 70%; the API figure is consistent with SBP but is not account-level evidence.
